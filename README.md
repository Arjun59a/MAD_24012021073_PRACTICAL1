# MAD_24012021073_PRACTICAL1

A Kotlin-based practical project for learning basic programming concepts in Android/Java ecosystem. This repository contains several small console programs demonstrating variable declarations, data types, input/output operations, and basic control flow.

## About the Project

This repository was created as part of a Mobile Application Development (MAD) practical exercise. It focuses on understanding:

- Kotlin syntax and structure
- Primitive data types
- Variables and constants
- User input and console output
- Basic loops and printing values
- Simple practical programs for learning fundamentals

## Files Included

- `src/Main.kt` — basic Kotlin example with `Hello, Kotlin!` and a loop.
- `src/p1_1.kt` — demonstration of variable types such as `Int`, `Float`, `Double`, `Char`, `String`, and `Boolean`.
- `src/pr1_3.kt` — student details program that reads and prints enrollment, name, branch, class, batch, college, university, and age.
- Other Kotlin files in `src/` contain additional practical exercises related to Kotlin fundamentals.

## Prerequisites

Before running the project, make sure you have:

- JDK installed
- IntelliJ IDEA or Android Studio
- Kotlin plugin (usually included in IntelliJ/Android Studio)

## How to Run

### Option 1: Using IntelliJ IDEA / Android Studio

1. Open the project in IntelliJ IDEA or Android Studio.
2. Open any Kotlin file in the `src` folder.
3. Click the Run button or use the IDE's Kotlin run configuration.

### Option 2: Using Kotlin CLI

```bash
kotlinc src/*.kt -include-runtime -d app.jar
java -jar app.jar
```
